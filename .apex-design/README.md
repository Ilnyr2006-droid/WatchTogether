# Planning workspace

This folder keeps reviewable designs for non-trivial WatchTogether changes. Each
initiative has a brief, glossary, requirements, design, implementation plan, and
progress board. `D-`, `R-`, and `T-` identifiers connect the reasoning.

## Initiatives
- 001-video-reconnect-hardening — Correct video timing and playback intent; define Host recovery semantics and cover reconnect/P2P edge cases — planned
- 002-watchtogether-architecture-review — Review room-state boundaries, token exposure, mesh capacity, and browser lifecycle coverage — drafting
- 003-playlist-local-media — Add a room playlist and owner-scoped local media streaming over authenticated HTTP Range — implementing
- 004-cinema-visual-system — Redesign landing and room UI around a quiet cinematic visual system without changing realtime behavior — complete
